# ZhBot v0.2.7

## 使用变化

- `帮助` 首行是 `@我 后输入`，猜测示例为 `我猜是 [单词]`
- 没有匹配内置指令或问答时，回复 `我没听懂哦~`，下一行 `试试@我发送“帮助”吧`
- 管理窗口增加「简单问答」：新增问题，编辑 1～20 条候选回复，点击保存即生效。群内真实 @ 后精确匹配（去首尾空白），所有允许群共用，随机选一条；不增加帮助条目。支持编辑、搜索、删除和多行回复，内置指令保留优先级
- 点击窗口 X 隐藏至系统托盘；左键恢复，右键有「打开窗口」「运行状态」「退出程序」。Tooltip 显示最近一次状态；再次双击 EXE 恢复当前项目原窗口。退出等待后台服务正常停止后关闭进程，窗口内「正常停止」保留管理窗口

本次更新需要包含新 `ZhBot.exe`，此后仍使用这个固定文件名入口。先正常停止旧机器人，关闭旧管理窗口，再更新项目文件并启动。数据库、配置、媒体、`.venv`、`.python` 和固定 helper 目录保留；新机器安装仍使用 `powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1`。日常在微信登录机器人后双击 `ZhBot.exe`；命令行可用 `.\.venv\Scripts\python.exe launcher/control.py start`，`status` 查询，`shutdown` 等待正常停止。

## 词库与存储

按指定仓库固定提交 `6b2ce3432d5753d2b77724e0255ca6d4d019d34d` 合并五字母词条。种子现有 2,316 个五字母答案、12,972 个五字母可猜词；3～10 字母总计 4,055 答案、14,711 可猜词。该上游只有五字母列表，其他长度保留。上游未提供明确开源许可证，来源说明、摘要与核查范围见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

已有数据库只增补一次新种子词，不覆盖现有词的属性，不恢复管理员删除的旧种子词；导入后删除的词也不在重启时回填。旧版本曾手动添加又删除、但不在旧种子中的新上游词没有删除记录，本次增补仍可能加入。已有开局快照保留，不随管理员修改或扩词而改变。

表情按原件摘要复用已有发送文件，新增未经转换的 GIF 与原件共用物理文件。Wordle 新局共用词库快照，相同棋盘共用 PNG，专用缓存按 7 天/128 MiB 目标回收并保护未完成发送。历史、原件、旧媒体及备份保留；独立新资源仍会增长。完整范围见 [存储审查](STORAGE.md)。

## 文件与调用关系

`ZhBot.exe`（`launcher/Launcher.cs`）维护管理窗口、托盘和单实例恢复，调用 `launcher/control.py` 控制独立后台进程与本机管理 API。退出命令等待机器人停止，窗口隐藏不提交停止请求。

`admin.py` 调用 `qa.py` 管理 `simple_qa`，`router.py` 在现有群权限/真实 @/冷却/暂停规则下匹配问题。随机回复与业务处理一同进入事务和 outbox；后续发送、失败重试与重启复用已选文本。

`dictionaries.py` 读取 `word_space_upgrade.json` 执行有版本标记的一次性增补，`word_space.NOTICE` 随 wheel/源码包/Windows 包保留。`wordle/store.py` 管理共享词库快照，`board_cache.py` 与 `runtime.py` 管理棋盘缓存，`stickers.py` 管理原件和发送文件复用。生产 helper 继续固定 `3e65e4bdaff438dc616f32d412175842fa138763`，许可和原生生命周期组件保留。

数据仍在 `runtime/`；升级前一致性数据库备份为 `runtime/backups/bot-before-v027.sqlite3`。配置、原生标识及真实聊天不进入发行包。群指令完整列表见 [README](../README.md#群指令)。
