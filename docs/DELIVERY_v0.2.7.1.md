## 迁移与文件

`dictionaries.py` 使用新的 `word_lists:` 标记，向现有数据库只加入相对 v0.2.7 种子的新增词。旧 `word_space:` 迁移固定为原 v0.2.7 种子的差集，支持从 v0.2.6 直接升级。已有词条使用 `INSERT OR IGNORE` 保留属性；管理员删除的旧种子词不回填，新增词导入后删除也不在下次启动恢复。以前手动加入又删除、且不在旧种子内的新上游词没有删除记录，本次可能重新加入。

`word_lists_upgrade.json` 保存来源摘要及 v0.2.7 种子，用于迁移和核对；`word_space_upgrade.json` 原内容保留，极早版本的对局补快照继续使用旧词库。新开局使用扩充后的运行词库，已开局的允许词快照、答案和次数不变。

运行数据仍位于 `runtime/`，升级前一致性备份为 `runtime/backups/bot-before-v0271.sqlite3`。不清理用户媒体、历史或已有备份。

上游 package.json 声明 ISC，未提供独立许可正文；其 README 注明的原始数据来源 `dwyl/english-words` 使用 Unlicense。声明及所核对的原始来源许可文本已随包保留，见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 验证

3 项词库迁移整合通过（5.34 秒），覆盖旧版升级、新库去重、旧属性/删除保留、一次性增补和旧局续局。隔离复制库中，初次增补约 0.50 秒，后台词库分页约 0.35～0.38 秒，3/5/10 字母开局约 0.27～0.30 秒；这些是本机单次测量，不是性能保证或群收发验收。

后续本机运行核对与构建结果记于 [兼容记录](COMPATIBILITY.md)。既有群功能的验收记录保留，本次不新增微信版本或后台条件结论。
